# Астрологический движок (astro)

Программа для расчета астрологических данных.

## Основные параметры (глобальные)
Эти флаги можно использовать с любой командой:

- `--format`, `-f` : Формат вывода. Доступные значения: `console`, `json`, `text`, `svg`, `png`. (По умолчанию: `console`)
- `--out-dir`, `-o` : Папка для сохранения файлов на сервере. (По умолчанию: `./output_data`)
- `--hsys` : Система домов. (По умолчанию: `P` — Placidus)

---

## Команды

### 1. natal
Вычисление натальной карты.
- `--date` : Дата и время в формате UTC (YYYY-MM-DD HH:MM). Если флаг `--date` не передан, программа автоматически запускается в **интерактивном режиме CLI**, собирая данные пользователя, запрашивая геокоординаты и рассчитывая часовой пояс.
- `--lat` : Широта (по умолчанию: 55.75)
- `--lon` : Долгота (по умолчанию: 37.61)

### 2. synastry
Вычисление синастрии или транзита двух карт.
- `--date1` : Дата Натала в UTC (YYYY-MM-DD HH:MM)
- `--date2` : Дата Транзита/Партнера в UTC (YYYY-MM-DD HH:MM)
- `--lat` : Широта Натала (по умолчанию: 55.75)
- `--lon` : Долгота Натала (по умолчанию: 37.61)
*Примечание: Если обязательные даты не переданы через флаги, команда запускается в интерактивном режиме.*

### 3. period
Расчет положения планет и аспектов за диапазон дат.
- `--start` : Старт периода UTC (YYYY-MM-DD HH:MM)
- `--end` : Конец периода UTC (YYYY-MM-DD HH:MM)
- `--step` : Шаг расчета в часах (например: 1, 6, 24; по умолчанию: 24)

### 4. calendar
Календарь астрособытий за месяц или год с возможностью автоматического учета часового пояса города.
- `--year` : Год расчета (по умолчанию: 2026).
- `--month` : Месяц расчета (1-12). Если 0 или не указан — считает за весь год.
- `--city` : Название города для автоматического определения часового пояса и смещения времени (например, `"Moscow"`, `"Tokyo"`). Если не указан, расчет ведется по UTC+0.
*Примечание: Если флаги года и месяца не переданы, запускается интерактивный CLI-опрос.*

## Новые возможности и изменения

### 1. Интерактивный CLI-режим
Команды `natal`, `synastry` и `calendar` поддерживают полноценный интерактивный режим сбора данных. Если запустить их без параметров:
- Программа пошагово запросит дату, время, признак местного времени и город.
- Автоматически обратится к геокодеру для определения координат, временной зоны и актуального смещения времени.
- Попросит подтвердить корректность введенных данных перед началом расчетов.

### 2. Поддержка часовых поясов по городам в календаре событий
- Реализована возможность автоматического расчета даты-времени событий календаря по указанному городу.
- Если город не указан (или пропущен по Enter в интерактивном режиме), время выводится в UTC+0.
- Если город указан, скрипт динамически запрашивает геоданные и временную зону через сервис `geo_date`, формирует объект `time.Location` и автоматически корректирует время событий (с учетом перевода часов на летнее/зимнее время).
- Смещение и название города выводятся в консоли, тексте и JSON (поле `timezone` в `AstroResult`).

## Поддержка форматов вывода по командам

Не все команды поддерживают визуализацию в формате `image` (SVG/PNG). Используйте следующую таблицу для выбора формата вывода:

| Команда | JSON | Text | Image (SVG/PNG) |
| :--- | :---: | :---: | :---: |
| **natal** | ✅ | ✅ | ✅ (Карта) |
| **synastry** | ✅ | ✅ | ⚠️ (Как натальная карта) |
| **period** | ✅ | ✅ | ❌ |
| **calendar** | ✅ | ✅ | ❌ |

- **JSON**: Рекомендуется для интеграции и автоматизации.
- **Text**: Рекомендуется для чтения человеком.
- **Image**: Поддерживается только для натальных карт и синастрии (в виде круговой диаграммы).

### Особенности формата `console`
Формат `console` предназначен для удобного чтения в терминале и использует табличную верстку:
- **natal**: Подробные таблицы планет (с координатами и скоростью) и аспектов.
- **synastry**: Сравнительная таблица межкартовых аспектов.
- **period**: Построчный лог положений планет для каждого временного среза.
- **calendar**: Чистый список событий в удобном для чтения виде.
